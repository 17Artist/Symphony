## 简介

Symphony 是基于 Blink 的属性与战斗插件。服务器可以使用 YAML 定义属性、伤害通道、元素反应、套装、词条、宝石、强化、物品技能和战力公式，并通过回调与公共 API 组合自己的玩法规则。

物品由 [Overture](https://github.com/17Artist/Overture) 创建和保存，Symphony 负责解析物品能力、维护实体属性快照并执行伤害结算。等级、角色成长和其它外部系统可以通过提供者与属性来源 API 接入。
